## 什么是织界？

**织界** 是一个前所未有的 AI 文字冒险世界。

没有预设的剧本，没有固定的选项。你写下你想做的一切——AI 会为你即时生成独一无二的剧情。每一个 NPC 都有性格，每一个选择都有后果，每一个世界都因你的存在而不同。

> 你想修仙？踏入一个灵气复苏的东方大陆。
> 你想科幻？飞向群星之间的未知疆域。
> 你想悬疑？走进一座迷雾笼罩的古老庄园。

**任何世界，任何故事，你说了算。**
